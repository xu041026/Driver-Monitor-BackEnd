连接监测终端

接入说明

让驾驶监测终端将识别到的事件发送到平台。

前往设备管理
01

登记设备

在设备管理中选择“接入新设备”，填写设备标识与名称，取得该设备的独立密钥。初次管理账户在本机调试模式创建；生产部署请由管理员使用 createsuperuser 初始化。

02

配置终端

将平台地址、设备标识和密钥配置到驾驶监测终端。密钥仅在创建时显示，请妥善保存。

03

确认上报

终端完成一次事件上报后，在告警记录中查看该事件，并检查发生时间与现场图片。

事件上报接口

以下内容供终端程序接入使用

POST
POST/api/v1/events/

请求地址为当前平台域名加以上路径，请求体使用 JSON。

请求头内容
Content-Typeapplication/json
X-Device-ID已登记的设备标识
AuthorizationBearer <设备密钥>

请求示例

示例字段仅说明格式，不会生成演示告警

{
  "event_id": "14b983d4-0bfa-40ca-94d9-dcfb92cccb9c",
  "event_type": "eye_closure",
  "occurred_at": "2026-09-23T10:30:00+08:00",
  "severity": "warning",
  "duration_ms": 2300,
  "confidence": 0.92,
  "details": {"ear": 0.16},
  "evidence": null
}

实际发送时请为每个新事件生成唯一 UUID，并使用真实发生时间。同一次事件重试时保留原事件编号，避免重复记录。

字段说明

必填字段保证事件能够被正确记录

字段要求说明
event_id必填UUID 格式的事件唯一编号；用于识别重复上报。
event_type必填从下方行为类型中选择一个标识。
occurred_at必填带时区的 RFC 3339 时间，例如 2026-09-23T10:30:00+08:00。范围为 2000-01-01T00:00:00Z 至服务器当前时间后 24 小时（含边界）；超出时请检查终端时钟。
severity可选warning 表示警告，critical 表示严重；省略时默认为警告。
duration_ms可选事件持续时长，单位毫秒，非负整数。
confidence可选终端检测置信度，范围 0–1。
details可选JSON 对象，用于保存阈值、检测结果等补充信息。
evidence可选现场图片对象，含 content_type 与 data_base64；无图时省略或设为 null。

行为类型

终端与平台使用同一组类型标识

eye_closure

现场图片

图片随事件保存在服务器本地磁盘

支持 JPEG 和 PNG。将图片文件内容编码为 Base64，填写到图片对象中。

"evidence": {
  "content_type": "image/jpeg",
  "data_base64": "<图片的Base64内容>"
}

Base64 内容不包含 data:image/…;base64, 前缀。图片查看需登录平台。

当前使用本地磁盘存储。异常断电或强制结束进程后可能留下无对应事件的图片文件，需由管理员核对处理。

手部异常表示终端检测到的手部状态；单纯张掌不能证明双手离开方向盘。
